An assertion whose expected value is BUILT by applying the same table, template or function the production code applies tests nothing: it is an identity, green for every possible content of that table.

Measured (job_hunt, 2026-10-11): every refusal-wording table in the repo was written as the END of the sentence "N things …", so the verb agreed with a count the table never saw.
A run printed `1 are internships` and `1 ask for more experience than a new graduate` for the user.
The test asserting the clauses read `` expect(clauses).toEqual([`1 ${ALERT_REFUSAL_WORDING.senior_title}`]) `` — it composed the expectation out of the table under test, so it was green whatever the table said, and the defect shipped through a green suite and eleven reasons.
The defect surfaced only when a NEW assertion, for a new line, wrote the whole sentence out as a literal and disagreed with the code.

**Why:** composition reproduces the code's own transform, so the only thing left to differ is nothing.
A literal is written by a human reading the product's output, which is where the defect lives.

**How to apply:**
- Write at least one expectation per generated-text surface as a byte-for-byte LITERAL, including the whole happy-path sentence and the ABSENCE of the clauses that did not apply — `[[assert-complete-message-not-substring]]`.
- Where a table is swept (so a literal per row is not practical), assert the PROPERTY the composition cannot satisfy: here, that the clause agrees with its count (`clauseOf(1, w) === '1 ' + w.one` **and** `clauseOf(2, w) === '2 ' + w.many`), which requires both forms to EXIST and is therefore a type-level census too.
- Encode the constraint in the SHAPE: a `{ one, many }` required pair makes a one-form entry a compile error at the table, rather than a sentence nobody reads until she does — `[[encode-the-invariant-in-the-shape-not-another-guard]]`.
- Fix it as a CLASS: the second table in the repo had the same defect, and the shared join (count → clause) is now one function both go through — `[[fix-the-class-not-the-reported-instance]]`.
- The same trap wears other clothes: a golden file regenerated by the code it guards, a snapshot updated on every red, a fixture built by the parser under test — `[[a-mention-is-not-a-property]]`.
