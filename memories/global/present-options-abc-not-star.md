When presenting options — in AskUserQuestion or the brainstorming visual companion — label them with plain letters **A/B/C** (use ✓ only for a literal approve/validate action). Do **not** use ★ as a selectable option key.

**Why:** you found ★-as-an-option-label confusing/unwanted during your-data-product brainstorm.

**How to apply:** put "(recommended)" in the option's label text, or state the recommendation in prose — never substitute a star glyph for the option letter.
